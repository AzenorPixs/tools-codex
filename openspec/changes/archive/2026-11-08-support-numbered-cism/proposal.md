# Proposition — code non attribué : CISM numéroté

## Why
PROMPT ne reconnaît pas les variantes numérotées directes de CISM.

## What Changes
Ajouter CISMx et 1CISMx, avec conservation du numéro et limite à un change pour la seconde variante.

## Capabilities

### New Capabilities
Aucune.

### Modified Capabilities
- `prompt-dispatch` : résolution des variantes directes numérotées.

## Impact
Résolveur, skill, documentation, tests et release commune ; aucun pilotage implicite.
