---
description: Lister ou lancer un prompt du projet courant depuis le référentiel DEVOPS.md
argument-hint: LIST|CODE_EN_MAJUSCULE
---

Utilise le skill `prompt` pour `/prompt $ARGUMENTS`. Résous les sources depuis
le DEVOPS.md du projet courant, puis son index déclaré, sans repli global.
LIST affiche l'index sans exécution. Un code valide charge le prompt et lance
son processus jusqu'à sa condition terminale ou une condition imposant de
rendre la main. Les variantes 1CISMP1 à 1CISMP8 sont limitées à un change,
archivage, statistiques puis arrêt de la session de codage ; conserver le RUN.

Ne transforme pas silencieusement les codes en minuscules. N'exécute pas un
prompt manquant ni un code inconnu. Cette commande source n'enregistre pas
automatiquement une slash native ; le skill est invocable avec `$prompt`.
